# Jatin Naik - Portfolio

Personal portfolio of Jatin Naik, final-year B.Tech IT student (class of 2027), open to entry-level roles.

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Run it locally

```
cd site
python -m http.server 8000
```

Open http://localhost:8000.

## Project layout

- `site/` is the website (this is what gets deployed).
- `docs/design.md` is the design system, `docs/architecture.md` the technical blueprint.
- `docs/DEPLOYMENT.md` is the step-by-step deployment guide.
- `docs/tools-and-skills.md` lists the skills and MCP servers worth using with a coding agent.
- `AGENTS.md` holds the instructions for AI coding agents working on this repo.
- `skills/anti-slop-audit/` is a reusable audit skill.

## Update content

- Projects: edit `site/js/data.js`. Add screenshots to `site/assets/img/` and set `img`.
- Experience, skills, About text: edit `site/index.html`.
- Resume: replace `site/assets/Jatin-Naik-Resume.pdf`.
