Project screenshots go here.

1. Capture a landscape (16:10) desktop screenshot, at least 1200px wide, no personal data.
2. Convert to WebP (https://squoosh.app) at about 1400px wide, quality 80.
3. Save as sentinelx.webp, setu-drishti.webp, vigam.webp (docvault.webp is already here).
4. In js/data.js set img:'assets/img/sentinelx.webp' for that project.
